LICENCA DE USO — LORD MARKETPLACES ANALYTICS

Versao: ver README.txt do pacote.

1. O QUE ESTE SOFTWARE FAZ
   O Lord Marketplaces Analytics le, no navegador ja autenticado pelo proprio
   usuario, as paginas de painel de vendedor dos marketplaces suportados
   (Mercado Livre e Shopee) e grava o que le em um banco de dados local, neste
   computador. Nao existe servidor do produto, conta na nuvem nem envio de
   dados para terceiros.

2. O QUE ESTE SOFTWARE NAO FAZ
   - Nao acessa API oficial dos marketplaces.
   - Nao pede, le, guarda nem transmite senha, cookie, token ou sessao de
     marketplace.
   - Nao faz login por voce.
   - Nao envia dados a nenhum servidor nosso (nao existe um).
   - Nao garante lucro, ranking, preco ou resultado comercial de qualquer tipo.

3. RESPONSABILIDADE DO USUARIO
   O software opera sobre a sessao que o usuario ja abriu legitimamente no seu
   proprio navegador, em conformidade com os termos de uso de cada marketplace.
   Cabe ao usuario verificar se o uso e permitido pelos termos do marketplace
   correspondente, e manter a confidencialidade dos dados que o software grava
   na sua maquina.

4. DADOS E PRIVACIDADE
   Todos os dados ficam em %LOCALAPPDATA%\LordMarketplacesAnalytics\.
   A desinstalacao NAO apaga o banco de dados: o dado pertence ao usuario.
   A consulta opcional ao Gemini envia apenas o resumo que o usuario autorizar
   explicitamente, com cota local e registro em auditoria.

5. GARANTIAS
   O software e fornecido "como esta", sem garantia de qualquer especie,
   expressa ou implicita, incluindo adequacao a um proposito especifico.
   Nenhum dado simulado e apresentado como real: campo nao coletado aparece
   como nao coletado, nunca como zero.

6. LIMITACAO DE RESPONSABILIDADE
   O autor nao responde por lucros cessantes, perda de dados ou danos
   indiretos decorrentes do uso ou da impossibilidade de uso do software.

7. ACEITE
   Instalar e usar o software significa aceitar estes termos.
